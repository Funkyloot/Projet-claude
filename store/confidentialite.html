Politique de confidentialité de Pistonville

Dernière mise à jour : 2 octobre 2026.

Pistonville est un jeu pour Android. Cette page explique quelles données le jeu utilise. En bref : aucune donnée personnelle n'est collectée, envoyée ni partagée.

Données collectées

Aucune. Le jeu n'a pas accès à Internet (il ne demande pas cette permission), n'utilise pas de compte, pas de publicité, pas d'outil de mesure d'audience et pas de service tiers.

Ta partie

Ta progression (garage, voitures, réglages) est enregistrée uniquement sur ton téléphone, dans le stockage de l'application. Si la sauvegarde Android de ton compte Google est activée, Android peut inclure ces données dans la sauvegarde de ton téléphone, selon tes propres réglages ; le développeur n'y a pas accès. Désinstaller le jeu efface la partie.

Permissions

Le jeu demande seulement la permission de faire vibrer le téléphone lors des chocs en course (désactivable dans les paramètres du jeu).

Enfants

Le jeu ne collecte aucune donnée, y compris auprès des enfants.

Changements

Si une future version du jeu devait utiliser des données (par exemple des publicités ou des statistiques d'utilisation), cette page serait mise à jour avant, et le jeu te demanderait ton accord quand la loi l'exige.
