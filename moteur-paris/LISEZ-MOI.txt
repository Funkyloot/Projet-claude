MOTEUR DE PARIS — installation

=== WINDOWS 10 / 11 ===

1. Décompressez MoteurDeParis.zip (clic droit › « Extraire tout »).

2. Ouvrez le dossier et double-cliquez sur « Installer Moteur de paris.bat ».
   Une seule fois, quelques minutes, internet nécessaire.
   - Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires »
     › « Exécuter quand même » (le fichier vient d'internet et n'est pas signé, c'est normal).
   - Si Python n'est pas installé, l'installateur l'installe depuis la source officielle
     (winget de Microsoft, Python de python.org). Une fenêtre peut demander votre accord.
   - Si Windows demande l'accès au réseau pour Python : cochez « Réseaux privés ».

3. Double-cliquez sur l'icône « Moteur de paris » du bureau (aussi dans le menu Démarrer).
   L'application s'ouvre dans sa propre fenêtre. Créez votre mot de passe, puis suivez
   « Pour commencer » sur le tableau de bord.

L'application est installée dans %LOCALAPPDATA%\MoteurDeParis (vos données : sous-dossier data).
Le dossier décompressé n'est plus nécessaire après l'installation.
Pour l'arrêter : menu Démarrer › « Arrêter Moteur de paris ».
Pour mettre à jour : décompressez la nouvelle version et relancez l'installateur (données conservées).

Consommation : presque rien en temps normal (le moteur attend). Le seul calcul lourd est le
backtest (au premier lancement, puis le dimanche à 2 h) : il tourne en priorité basse et laisse
toujours un cœur libre. Vous pouvez jouer en même temps ; si un jeu très lourd rame pendant ce
calcul, arrêtez le moteur le temps de jouer.

=== LINUX (Ubuntu, Debian, Mint…) ===

Double-cliquez sur « Installer Moteur de paris.desktop » (ou « bash installer.sh » dans un terminal),
puis sur l'icône « Moteur de paris » du bureau. Arrêt : arreter.sh.

=== IPHONE / ANDROID ===

Le PC allumé et le téléphone sur le même Wi-Fi : ouvrez Safari, tapez http://adresse-du-pc:8080
(l'adresse IPv4 s'obtient sur le PC avec la commande « ipconfig »), puis Partager › « Sur l'écran d'accueil ».
L'icône « Paris » s'ouvre alors en plein écran comme une application, toujours à jour.
Hors de chez vous : installez Tailscale (gratuit) sur le PC et sur l'iPhone, puis utilisez l'adresse Tailscale du PC.

=== Bon à savoir ===
- Tout se règle dans l'application (page Réglages) : Telegram, championnats, capital, seuils.
- Depuis le téléphone, sur le même Wi-Fi : http://adresse-du-pc:8080
- Sources utilisées : Python officiel, dépôt officiel PyPI, données publiques football-data.co.uk.
